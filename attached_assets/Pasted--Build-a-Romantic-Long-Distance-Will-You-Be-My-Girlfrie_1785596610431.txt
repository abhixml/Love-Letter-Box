# Build a Romantic Long-Distance “Will You Be My Girlfriend?” Website

Build a complete, polished, highly interactive romantic website that I can send to a girl I like. The website is a playful proposal asking her:

**“Will you be my girlfriend?”**

The relationship is **long-distance**, so the website should incorporate the idea that distance is annoying, but the connection still matters.

The overall experience should be:

* 45% cute
* 30% funny / meme humour
* 20% romantic
* 5% emotional
* Very personalized-feeling
* Never corporate
* Never generic AI-looking
* Never overly cheesy
* Mobile-first because she will probably open it on her phone

The humour should feel like Reddit/internet humour: self-aware, absurd, slightly dramatic, cute, and relatable.

Use **cute cat reaction memes / cat illustrations** throughout the website.

---

# TECH STACK

Use:

* React
* Vite
* JavaScript or TypeScript
* Tailwind CSS
* Framer Motion for animations
* Lucide React for icons
* Responsive design
* Local state only unless absolutely necessary

Do NOT build a backend unless needed.

The website must work immediately with:

```bash
npm run dev
```

Make sure there are no broken imports, missing assets, or console errors.

---

# IMPORTANT DESIGN DIRECTION

Do NOT make this look like a business website.

It should feel like:

> “Someone spent an unreasonable amount of time making an adorable website because they like this girl.”

Use a romantic visual style:

* soft pink
* cream
* white
* subtle red
* lavender
* warm gradients
* rounded cards
* cute shadows
* subtle glassmorphism
* floating hearts
* tiny stars
* little cat illustrations
* smooth transitions

Avoid:

* dark hacker aesthetic
* excessive neon
* corporate dashboards
* huge amounts of text
* cheesy stock photos
* generic AI gradients
* excessive animations that make the site annoying

Use beautiful typography with one elegant serif/display font for romantic headings and a clean sans-serif font for body text.

---

# CAT ASSET STRATEGY

Use cute cat images/illustrations throughout.

If external image URLs are used, use reliable public image sources and make sure the website still looks good if an image fails.

Prefer:

* cute white cat
* orange cat

* confused cat
* shocked cat

---

# MOBILE DESIGN

This is extremely important.

Optimize for:

* iPhone
* Android
* 360px–430px widths

Buttons must be large enough to tap.

No horizontal scrolling.

No tiny text.

No hover-only functionality.

Use responsive typography.

The website should feel even better on mobile than desktop.

---

# PERSONALIZATION

At the top of the source code, create a simple configuration object:

```js
const CONFIG = {
  herName: "HER_NAME",
  myName: "MY_NAME",
  date: "DATE",
  nickname: "NICKNAME",
};
```

Use these values throughout the website.

Make it easy for me to change her name, my name, nickname, and date without searching through the entire project.
